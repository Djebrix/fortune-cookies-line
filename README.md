## The fortune

> Your training ended yesterday; your confidence never got the memo.

## How it works

`main.py` (Python 3, stdlib only) writes that single line to `entry.txt` in the
output directory — `/output` by default, or `$ENTRY_OUTPUT_DIR` when set.
The output is deterministic: every run produces the same bytes.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
